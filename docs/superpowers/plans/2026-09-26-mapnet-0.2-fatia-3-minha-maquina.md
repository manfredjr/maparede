# Plano da fatia 3: painel "Minha máquina" completo

Ramo `minha-maquina`. Desenho em `docs/superpowers/specs/2026-09-25-mapnet-0.2-painel-do-tecnico-design.md`, seções 4 e 8.

Este plano vem antes do código. O código só começa depois que o Manfred aprovar este PR.

## Objetivo

Completar a coluna "Minha máquina" com tudo o que o técnico precisa saber do computador em que está, sem administrador: identificação da máquina, detalhes da placa, IPv6, DHCP, Wi-Fi e IP público sob demanda. O relatório HTML ganha a mesma seção. A fatia sai como versão 0.2.2, porque a 0.2.1 foi usada para corrigir a tela da 0.2.0.

## O que entra

| Grupo | Informação | Fonte |
|---|---|---|
| Computador | Nome, grupo de trabalho ou domínio, usuário logado | `Environment` e `IPGlobalProperties` |
| Placa | Nome, tipo, MAC, velocidade do link, MTU | `NetworkInterface` e `GetIPv4Properties()` |
| Endereços | IPv4 com máscara, IPv6 (global e de link local), gateway, DNS, sufixo DNS | `IPInterfaceProperties` |
| DHCP | Ligado ou fixo, servidor DHCP, concessão obtida e validade | `GetIPv4Properties().IsDhcpEnabled`, `DhcpServerAddresses` e `GetAdaptersInfo` do `iphlpapi` para as datas da concessão |
| Wi-Fi | Rede (SSID), banda (2,4, 5 ou 6 GHz), canal, sinal em porcentagem | API de WLAN do Windows (`wlanapi.dll`), que não depende do idioma. Só para placa Wi-Fi |
| IP público | Botão **Consultar IP público**, sob demanda | `https://1.1.1.1/cdn-cgi/trace`, do Cloudflare, recomendação da seção 8 do desenho |

Entra também um ajuste na tabela de hosts, visto no teste da 0.2.1 na rede do Manfred: com a janela no tamanho padrão (1180 de largura), textos ficam cortados nas colunas de largura fixa ou estreita. Os casos vistos foram "DNS reverso" na Origem (78), "MAC aleatório (privado)" no Fabricante e o nome da máquina no Nome. A correção dá largura mínima a cada coluna pelo texto mais longo que ela pode ter, mostra o texto inteiro na dica ao passar o mouse e mantém a rolagem lateral só abaixo da largura mínima da janela (960).

Fora desta fatia: botões de manutenção (fatia 5) e ferramentas do console (fatia 4).

## Decisão que a aprovação deste plano fecha

A seção 8 do desenho deixou "a confirmar" o serviço do IP público. Este plano usa `https://1.1.1.1/cdn-cgi/trace`: é do Cloudflare, que a MT já usa, responde texto simples (`ip=...`) e não pede cadastro. Aprovar o plano aprova esse serviço.

## Regras

- **Nada sai para a internet sem clique.** O IP público só é consultado quando o técnico aperta o botão, com tempo limite de 5 segundos. O resultado vai para o painel, para o console e, se o técnico gravar o relatório depois, para o relatório.
- **Wi-Fi no Windows 11 recente:** a API de WLAN pode negar o SSID quando a Localização do Windows está desligada. Nesse caso, o painel mostra "Wi-Fi: ligue a Localização do Windows para ver o nome da rede" em vez de erro, e o resto do painel continua.
- **Informação que não vem:** cada linha mostra "não informado" e o painel segue. Nenhuma falha de leitura derruba a tela.
- **A página muda uma frase:** a seção "O que ele não faz" diz hoje que o programa não envia nada para fora da rede local. Passa a dizer que a única consulta externa é a do IP público, e só quando o técnico clica.

## Arquitetura

- **Núcleo, pasta nova `maquina/`:**
  - `InformacoesMaquina`: os dados lidos, sem nenhum tipo do Windows;
  - `LeitorMaquina`: monta as informações a partir da interface escolhida;
  - `IFonteWifi` e `WifiWindows`: a leitura pela `wlanapi.dll`, atrás de uma interface, como o ARP;
  - `IConsultaIpPublico` e `IpPublicoCloudflare`: a consulta HTTP, também atrás de uma interface;
  - funções puras e testadas: interpretar a resposta do Cloudflare, banda a partir do canal, sinal em porcentagem, texto da validade do DHCP.
- **Painel:** `MinhaMaquina` passa a vir do `LeitorMaquina`, em grupos (Computador, Placa, Endereços, DHCP, Wi-Fi, IP público). Ganha o comando **Consultar IP público**, com os estados "consultar", "consultando...", o IP ou a mensagem de erro.
- **Janela:** a coluna mostra os grupos com títulos pequenos e o botão do IP público em pílula.
- **Relatório HTML:** seção "Minha máquina" no começo, com o que foi lido. O IP público só aparece se tiver sido consultado.

## Riscos

| Risco | O que fazer |
|---|---|
| `wlanapi.dll` não existe em Windows Server sem o recurso de rede sem fio | Carregar a biblioteca só quando a placa for Wi-Fi e tratar a falta como "não informado" |
| Localização desligada no Windows 11 esconde o SSID | Mensagem clara no painel, sem erro |
| Rede do cliente bloqueia `1.1.1.1` | Mensagem "não foi possível consultar" com o motivo, e o resto do programa segue |
| Leitura da máquina lenta ao trocar de interface | Leitura em segundo plano, com o painel mostrando "lendo..." |

## Como testar

1. Conferir que o CI do PR da fatia passou e ver as imagens da janela no PR.
2. Baixar o `mapnet.exe` em **Artifacts** e abrir no Windows, primeiro no cabo e depois no Wi-Fi.
3. Conferir nome, domínio, usuário, placa, IPv6, DHCP e, no Wi-Fi, rede, banda, canal e sinal.
4. Clicar em **Consultar IP público** e conferir com o que o site `https://1.1.1.1/cdn-cgi/trace` mostra no navegador.
5. Varrer e abrir o relatório: a seção "Minha máquina" aparece no começo.
6. Na tabela de hosts, com a janela no tamanho padrão, nenhum texto aparece cortado. Na largura mínima, a rolagem lateral mostra o resto.
